### 📞 Le Répondeur Romand

An AI phone assistant that picks up when you can't, for businesses that miss calls:
construction sites, restaurants, garages, property managers, medical and law offices.

- **Answers the call** and asks the caller the right questions
- **Sends a summary by e-mail**: the request, the callback number, the transcript and the recording
- **One-click reply**: the caller automatically gets an SMS in the business's name
- **No new number**: calls are simply forwarded to the assistant

Built and run with my friend Esteban Giorgis.

### 🏠 SmartBnB

**Is this Airbnb a good deal?** Paste a listing from canton Vaud and SmartBnB compares it
with similar stays nearby, summed up in a score out of 100.

- **Data pipeline**: monthly [Inside Airbnb](https://insideairbnb.com/) snapshots loaded into PostgreSQL
- **Explore the region**: price map, Top 10 lists and price trends by district
- **Stack**: Vue 3, Node.js + Express, Supabase Postgres, Cloudflare Workers

Live at **[smartbnb.ch](https://www.smartbnb.ch)**, open source on **[GitHub](https://github.com/AdamoElProfesor/SmartBnB)**.
